## 🎯 Project Overview

**Quantum Dynamics Lab** is a premium interactive visualization platform featuring 7 real-time physics simulations. Each simulation is built with actual physics engines, responsive controls, and a stunning dark-elegant UI.

This isn't a tutorial project — it's a **production-grade portfolio piece** designed to showcase deep understanding of physics, mathematics, and web technologies.

## 🌌 Seven Core Simulations

| Simulation | Physics Concept | Interaction | Complexity |
|-----------|-----------------|-------------|-----------|
| **Newton's Playground** | Force, Mass, Acceleration (F=ma) | Drag object, adjust parameters | Medium |
| **Lotus Effect** | Hydrophobicity, Surface Tension | Tilt surface, observe droplet behavior | High |
| **Plate Tectonics** | Continental collision, mountain formation | Time scrubber (geological scale) | Medium |
| **Murmuration** | Boid flocking, emergent behavior | Adjust separation/alignment/cohesion | High |
| **Ferromagnetism** | Magnetic fields, particle alignment | Click to place magnetic poles | High |
| **Fourier Circles** | Discrete Fourier Transform, signal decomposition | Draw shapes, visualize harmonics | Expert |
| **Gravity Tree** | N-body gravity, particle collision, emergence | Watch systems self-organize | Expert |

## 🚀 Quick Start

### Prerequisites
- Modern browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code recommended)
- Git

### Installation

```bash
# Clone repository
git clone https://github.com/ibawani/quantum-dynamics-lab.git
cd quantum-dynamics-lab

# Option 1: Use VS Code Live Server
# Install "Live Server" extension
# Right-click index.html → "Open with Live Server"

# Option 2: Use Python
python -m http.server 8000
# Visit: http://localhost:8000

# Option 3: Use Node.js
npx http-server
```
