How It's Built

Stack

VISIQ is a static site built with vanilla JavaScript. No frameworks, no bundlers, no build step.

  • HTML5 for semantic markup
  • CSS3 with custom properties for design tokens
  • Vanilla JavaScript (ES6+) for interactivity
  • p5.js for 2D simulations (instance mode)
  • Three.js for 3D simulations (vendored, pinned)
  • Vitest for unit tests
  • Python 3 for local development server (http.server)

Tests

Tests are written in JavaScript and run with Vitest. Test files are in the tests/ directory.

Run tests with:

npm test

Sources

External libraries are vendored with version, hash, license, and URL documented in docs/SOURCES.md.

  • p5.js - Creative coding library for 2D simulations
  • Three.js - 3D graphics library for hero simulations
  • Vitest - Test runner

All libraries are at least 14 days old and pinned to specific versions.

Limits

VISIQ is a static site with no backend. This means:

  • No user accounts or authentication
  • No cloud saves or data persistence
  • No leaderboards or social features
  • No telemetry or analytics
  • No real-time collaboration

All state is stored locally in the browser (localStorage for preferences, URL parameters for sharing simulations).

Browser Support

VISIQ requires a modern browser with ES6+ support:

  • Chrome 90+
  • Firefox 88+
  • Safari 14+
  • Edge 90+

Local Development

To run VISIQ locally:

python3 -m http.server 8000

Then open http://localhost:8000 in your browser.
